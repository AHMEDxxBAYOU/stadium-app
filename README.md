# تطبيق إدارة الملعب — نسخة أندرويد

هذا المشروع يحوّل ملف `index.html` إلى تطبيق أندرويد أصلي (Kotlin + WebView) فيه:

- الدخول ببصمة الهاتف الحقيقية (BiometricPrompt + شريحة الأمان Android Keystore) مع بقاء الدخول بكلمة المرور كالعادة.
- إشعارات الهاتف مع إذن رسمي من النظام، وأنت تختار أنواعها (حجز جديد، تعديل، حذف، تذكير قبل الموعد، إيراد، مصروف...).
- زر الرجوع في الهاتف يغلق النافذة المفتوحة أولاً، ثم يرجع للتبويب السابق، وفي الشاشة الرئيسية يطلب ضغطة ثانية للخروج.
- حفظ ملفات التصدير (PDF / Excel / JSON) في مجلد `Download/StadiumManager`، والطباعة من داخل التطبيق.

البناء يتم على خوادم GitHub مجاناً (GitHub Actions)، وأنت تتحكم بكل شيء من Termux على الهاتف.

---

## أولاً: تجهيز Termux (مرة واحدة)

1. ثبّت Termux من F-Droid أو من صفحة GitHub الرسمية (نسخة Google Play قديمة ولا تعمل جيداً):
   https://github.com/termux/termux-app/releases
2. افتح Termux ونفّذ:

```bash
termux-setup-storage
```
اسمح بالوصول للملفات عندما يطلب الهاتف ذلك. ثم:

```bash
pkg update -y && pkg upgrade -y
pkg install -y git gh unzip
```

3. سجّل الدخول لحساب GitHub (أنشئ حساباً مجانياً من github.com إذا لم يكن لديك):

```bash
gh auth login
```
اختر بالترتيب: `GitHub.com` ثم `HTTPS` ثم `Y` ثم `Login with a web browser`.
سيظهر لك رمز من 8 أحرف؛ انسخه، واضغط Enter، وسيفتح المتصفح، الصق الرمز ووافق.

4. عرّف اسمك لـ git (أي اسم وبريد):

```bash
git config --global user.name "Stadium"
git config --global user.email "you@example.com"
git config --global --add safe.directory '*'
```

## ثانياً: رفع المشروع وبناء التطبيق (أول مرة)

ضع ملف `stadium-app.zip` في مجلد التنزيلات `Download` في الهاتف، ثم:

```bash
cd ~
unzip -o /sdcard/Download/stadium-app.zip -d ~
cd ~/stadium-app
git init -b main
git add -A
git commit -m "النسخة الأولى"
gh repo create stadium-app --private --source=. --push
```

> مهم: اجعل المستودع **خاصاً (private)** كما في الأمر أعلاه، لأنه يحتوي مفتاح توقيع التطبيق.

البناء يبدأ تلقائياً على GitHub ويستغرق تقريباً 4–7 دقائق. لمتابعته:

```bash
gh run watch
```

عند ظهور علامة النجاح حمّل ملف APK إلى مجلد التنزيلات:

```bash
gh release download --pattern '*.apk' -D /sdcard/Download --clobber
```

ثم افتح مدير الملفات في الهاتف ← Download ← `StadiumManager-v1.apk` ← تثبيت
(إذا طلب الهاتف «السماح بالتثبيت من هذا المصدر» وافق).

يمكنك أيضاً تحميله من المتصفح: صفحة المستودع على GitHub ← **Releases** ← آخر نسخة ← ملف `.apk`.

## ثالثاً: أول تشغيل للتطبيق

1. افتح التطبيق. سيطلب منك بيانات الربط بـ Firebase (Project ID و apiKey والرمز السري) مرة واحدة فقط، لأن التطبيق جهاز جديد بالنسبة للمنظومة. أدخل نفس البيانات المستخدمة في المتصفح.
2. سجّل الدخول بكلمة المرور كالعادة. سيسألك التطبيق: «هل تريد تفعيل الدخول بالبصمة؟» ← نعم ← ضع إصبعك.
3. من المرة القادمة تظهر نافذة البصمة تلقائياً عند فتح التطبيق، ويوجد زر «الدخول بالبصمة» تحت زر الدخول، وتبقى كلمة المرور متاحة دائماً.

### إعدادات البصمة والإشعارات
- زر البصمة في الشريط العلوي (بجانب زر الخروج)، أو للمدير: تبويب **الموظفين** ← بطاقة **البصمة والإشعارات**.
- من هناك: تفعيل أو إيقاف البصمة، ومفتاح رئيسي للإشعارات، ومفاتيح لكل نوع، ومدة التذكير قبل الحجز، وزر «إرسال إشعار تجريبي».
- الإعدادات خاصة بكل هاتف؛ كل موظف يختار ما يناسبه.

## رابعاً: تحديث التطبيق لاحقاً

عندما تعدّل ملف الـ HTML، ضع الملف الجديد في التنزيلات باسم `index.html` ثم:

```bash
cd ~/stadium-app
cp /sdcard/Download/index.html app/src/main/assets/index.html
git add -A
git commit -m "تحديث"
git push
gh run watch
gh release download --pattern '*.apk' -D /sdcard/Download --clobber
```

ثبّت الـ APK الجديد فوق القديم مباشرة (البيانات تبقى كما هي).

> ملاحظة: إذا استبدلت `index.html` بنسخة جديدة من ملفك الأصلي، فهي لا تحتوي إضافات البصمة والإشعارات وزر الرجوع. انسخ الجزء الموجود بين `<style id="native-bridge-css">` ونهاية `</script>` الخاص بـ `native-bridge-js` (في آخر الملف قبل `</body>`)، والأسطر الثلاثة المعلّمة (`nb-bio-wrap` و `nb-hbtn` و `__nbAfterLogin`) إلى النسخة الجديدة، أو أرسل لي الملف الجديد وأنا أدمجها.

## معلومات مهمة

- **مفتاح التوقيع** موجود في مجلد `keystore/`. لا تحذفه ولا تغيّره؛ بدونه لا يمكن تثبيت التحديثات فوق النسخة القديمة.
- **الإشعارات من الأجهزة الأخرى** (حجز سجّله موظف آخر) تصل والتطبيق مفتوح أو في الخلفية. لكي تصل حتى بعد الخروج بزر الرجوع لفترة طويلة، فعّل خيار «البقاء متصلاً في الخلفية» (يظهر إشعار صغير ثابت). إذا أغلقت التطبيق بالسحب من قائمة التطبيقات الحديثة فلن تصل حتى تفتحه.
- **تذكير قبل موعد الحجز** يعمل حتى والتطبيق مغلق تماماً وبعد إعادة تشغيل الهاتف.
- بعض الهواتف (شاومي، هواوي، أوبو، سامسونج) توقف التطبيقات في الخلفية: من إعدادات التطبيق ← البطارية ← اختر «بدون قيود».
- إذا كان مفتاح Firebase API مقيّداً بمواقع معيّنة في Google Cloud، أضف `appassets.androidplatform.net` إلى القائمة المسموحة.
- عند إضافة بصمة جديدة للهاتف أو تغيير كلمة المرور، يُلغى الدخول بالبصمة تلقائياً للأمان، ويُعرض عليك تفعيله من جديد بعد الدخول بكلمة المرور.

### حل المشاكل
- `gh: command not found` ← نفّذ `pkg install gh`.
- فشل البناء ← نفّذ `gh run view --log-failed | tail -50` وأرسل لي النتيجة.
- `Permission denied` على `/sdcard` ← نفّذ `termux-setup-storage` مرة أخرى.
- «التطبيق غير مثبت» عند التحديث ← احذف النسخة القديمة أولاً (ستحتاج إعادة إدخال بيانات الربط).
